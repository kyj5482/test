# 초등학생의 첫 코딩은 무엇을 남겼을까?

`관심사: 커리어 스토리` · `퍼즐 3조각`

20년차 플랫폼 엔지니어의 성장기, 첫 조각. 시작은 초등학교의 코딩·알고리즘 수업이었다.

## 🧩 조각 1 — 화면 속 세계를 내가 움직인다는 감각

초등학생에게 코딩이 남긴 것은 문법이 아니었다. 몇 줄을 적으면 화면의 무언가가 **내가 시킨 대로** 움직인다는 감각.
이 감각은 게임을 하는 것과 완전히 다르다. 게임은 남이 만든 규칙 안에서 노는 것이고, 코딩은 규칙을 내가 쓰는 것이다.
이후의 모든 커리어는 이 감각의 확장이었다 — 화면 하나에서 홈페이지로, 로봇으로, 차량 100만 대로.

## 🧩 조각 2 — 고등학교, 처음으로 '사용자'가 생기다

고교 시절 학교 홈페이지를 만들었다. 기술적으로는 소박했지만 결정적 차이가 있었다:
**남이 쓴다**는 것. 내가 재미로 짜는 코드와 남이 쓰는 코드는 다른 물건이다.
링크가 깨지면 항의가 오고, 잘 만들면 고맙다는 말을 듣는다.
"작동하는 코드"에서 "책임지는 코드"로 — 첫 번째 직업적 전환은 이미 여기서 일어났다.

## 🧩 조각 3 — 이른 시작의 진짜 이점

일찍 시작해서 좋았던 것은 실력의 선행이 아니다 (문법은 어차피 몇 번씩 다시 배웠다).
진짜 이점은 **정체성이 일찍 생겼다**는 것 — 진로를 고민할 때 "나는 만드는 사람"이라는 좌표가 이미 있었다.
아이의 조기교육을 고민하는 부모에게도 같은 답을 한다: 기술이 아니라 정체성이 남는다.
수영이든 코딩이든, 이른 시작의 가치는 같은 곳에 있다.
