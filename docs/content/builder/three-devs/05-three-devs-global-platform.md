# 3명이 어떻게 글로벌 커넥티드카 플랫폼을 만들었나?

`관심사: 플랫폼` · `퍼즐 4조각`

2017년, 커넥티드카 서비스를 유럽부터 글로벌 런칭해야 했다.
한국·미국·중국은 각각 완전히 분리된 시스템, 서버 문서는 거의 없음, 나라 하나 런칭에 10억 이상.
이 문제를 3명이 풀었다. 유럽 → 한국 → 중국 → 인도, 2018년까지 순차 런칭에 운영까지.

## 🧩 조각 1 — 문제를 비즈니스 언어로 다시 정의한다

"시스템이 파편화되어 있다"는 엔지니어의 문장이다.
"나라 하나 추가할 때마다 10억+가 든다"는 경영진의 문장이다.
플랫폼 일원화 프로젝트가 승인된 것은 후자 덕분이다. **아키텍처를 팔지 말고, 비용 구조를 팔아라.**

## 🧩 조각 2 — 기술 선택: 적재적소 + 오픈소스

- **Go**: 성능이 중요한 서비스 (계정 개발에서 검증된 경험 재사용)
- **Node.js**: 데이터 처리 중심 서비스
- **보안**: 계정에 OAuth, 파트너사별 고객 데이터/차량 기능 인가에 JWT
- **API Gateway**: 온프레미스 DMZ존에 오픈소스 **tyk** — API가 추가되면 CI/CD가 tyk 설정까지 자동 반영

핵심은 "최신 기술"이 아니라 **3명이 운영까지 감당할 수 있는 자동화**였다.

## 🧩 조각 3 — 범위: API G/W, Account, Vehicle, Partner, App 서버까지

브랜드가 3개(현대·기아·제네시스)라는 건 사실상 회사가 3개라는 뜻이다.
각 사가 원하는 디자인·프로세스를 모두 대응하면서, 새 차량이 나올 때마다 세계 곳곳에서 직접 버그를 잡고 패치했다.
백업 플랜은 없었다. 실패하면 차량 출시가 흔들리는 구조. 해커들의 API 공격 소식이 들릴 때마다 심장이 멎는 듯했지만, 그 긴장이 시스템과 사람을 단단하게 만들었다.

## 🧩 조각 4 — 사람이 마지막 퍼즐이다

성과를 개발자들의 것으로 만들어주지 못하자, 팀원들은 결국 SKT·네이버로 떠났다.
팀장도 TF장도 아니었던 내가 할 수 있던 최선은, 그들이 **최고의 조건으로 떠날 수 있도록** 그 회사들에 그들의 가치를 설명해주는 것이었다.
플랫폼은 기술로 완성되지만, **지속은 보상 구조가 결정한다.** 이것이 이 프로젝트의 가장 비싼 교훈이다.
