# 📮 읽기만큼 쓰기도 — tutor.writing 소개호

수영 기록을 데이터로 남기던 습관을, 이번엔 아이의 글쓰기로 옮겼습니다.
아이들은 매일 책을 읽지만, 매일 쓰고 그때그때 눈높이 피드백을 받을 곳은 없었습니다.
부모가 영어 글쓰기를 매일 첨삭할 수도 없고, 작은 실수는 몇 주씩 반복되는데 아무도
그걸 추적하지 않았습니다.

그래서 만들었습니다. **tutor.writing** 은 Claude Code 위에 올린 '매일 글쓰기 튜터 에이전트'입니다.
`/setup`으로 아이 프로필을 만들고, `/today`로 읽은 책을 바탕으로 매일 한 편을 쓰고 피드백을 받고,
`/weekly`로 성장 리포트를, `/progress`로 레벨을 봅니다. 부모에게는 주간 한글 요약이 갑니다.

## 이 호에서 읽을 퍼즐 스토리

- **[아이의 글쓰기는 왜 매일 봐줄 사람이 없을까?](../writer/writing-tutor/01-why-daily-writing.md)** —
  이 도구가 태어난 문제. 읽기는 넘치는데 쓰기 피드백은 비어 있었습니다.
- **[빈 화면이 무섭지 않으려면 무엇을 먼저 보여줘야 할까?](../writer/writing-tutor/02-example-first.md)** —
  아이가 아는 책(Hatchet·The Giver)으로 만든 예시를 먼저 보여주는 '예시 먼저' 방식.
- **[아이에게 쓸모 있는 피드백은 몇 개면 충분할까?](../writer/writing-tutor/03-feedback-rubric.md)** —
  강점 2개 + 고칠 점 1개 + 도전 1개, 그리고 '절대 대신 써주지 않는다'는 원칙.
- **[같은 실수가 몇 주째 반복되는 걸 어떻게 잡을까?](../writer/writing-tutor/04-watch-list.md)** —
  반복 실수를 추적하고 3번 연속 깨끗하면 졸업시키는 Watch List.
- **[벌점 없이 계속하게 만드는 동기는 어떻게 설계할까?](../writer/writing-tutor/05-gamification.md)** —
  XP·10단계 레벨·연속 기록·배지. XP는 절대 깎이지 않습니다.
- **[한 학기의 성장을 어떻게 눈으로 보게 할까?](../writer/writing-tutor/06-portfolio-growth.md)** —
  모든 기록을 마크다운으로 남겨 학기 단위로 성장을 비교하는 포트폴리오.
