# 레이스 전 머릿속에서는 무슨 일이 일어날까?

`대상: AAA+ (전국 지향~최상위) · 13-14세~17-18세 · 남녀 공통` · `퍼즐 3조각`

챔피언십 레벨에서 기록의 차이는 대부분 어깨 위에서 난다.
콜룸(소집실)에서 무너지는 선수와 블록 위에서 더 단단해지는 선수의 차이.

## 🧩 조각 1 — 시각화는 미신이 아니라 리허설이다

최상위 선수들이 경기 전 눈을 감고 있는 것은 명상이 아니라 **레이스를 미리 헤엄치는 것**이다.
스타트 신호, 입수 감각, 첫 15m, 턴 개수, 후반 페이스업 지점까지 —
머릿속 리허설을 반복한 레이스는 몸에게 "처음"이 아니다.
결승 경험이 훈련이라던 원칙의 연장선: 실제 결승 기회가 부족하면 머릿속 결승으로 보충한다.

## 🧩 조각 2 — 루틴이 긴장을 흡수한다

큰 대회일수록 통제할 수 없는 것이 늘어난다. 낯선 수영장, 밀리는 일정, 옆 레인의 전국 랭커.
멘탈이 강한 선수의 비밀은 담력이 아니라 **통제 가능한 것들의 목록** — 워밍업 순서, 수경 조이는 횟수,
블록 뒤에서의 호흡 세 번 같은 루틴이다. 루틴이 차지한 머리에는 불안이 들어올 자리가 없다.

## 🧩 조각 3 — 실패의 시나리오도 준비물이다

"수경에 물이 들어오면? 스타트가 늦으면? 첫 50m가 계획보다 느리면?"
이 질문들을 대회 전에 답해두는 선수는 사고가 나도 레이스가 무너지지 않는다.
플랫폼 운영의 롤백 스크립트와 같다 — **장애 대응은 장애 전에 쓰는 것.**
9위의 대회에서 시작된 레이스 노트가 이 수준에서는 시나리오 플래닝으로 진화한다.
