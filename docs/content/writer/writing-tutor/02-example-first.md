# 빈 화면이 무섭지 않으려면 무엇을 먼저 보여줘야 할까?

`주제: 방법` · `퍼즐 3조각`

아이가 아는 책으로 '이렇게 쓰면 된다'는 예시를 먼저 보여주면, 흰 화면은 더 이상 벽이 아니다.

## 🧩 조각 1 — 아이가 무서워하는 건 주제가 아니라 빈 화면이다

글쓰기를 시키면 아이가 멈추는 지점은 늘 똑같았다. 주제를 몰라서가 아니라, **아무것도 없는
흰 화면** 앞에서 뭘 어떻게 시작할지 몰라서 멈춘다. 어른도 그렇다. 그래서 튜터의 첫 규칙을
"예시 먼저"로 잡았다. 아이가 쓰기 전에, 먼저 잘 쓴 답이 어떤 모양인지 보여준다.

## 🧩 조각 2 — 아이가 이미 아는 책으로 예시를 만든다

핵심은 **아이가 이미 아는 책**으로 예시를 만든다는 것이다. 6학년 작은아이에게는 *Hatchet*,
8학년 큰아이에게는 *The Giver* — 자기가 읽은 이야기라서 예시 답이 바로 이해된다. 낯선
지문으로 "이렇게 쓰렴" 하면 예시 자체가 또 하나의 벽이 되지만, 아는 책이면 "아, 이렇게
풀어가면 되는구나"가 즉시 온다. 예시는 베끼라는 게 아니라 **출발선을 보여주는** 것이다.

## 🧩 조각 3 — /setup으로 시작하고, /today로 매일 쓴다

흐름은 슬래시 명령으로 단순하게 만들었다. 처음에 `/setup`으로 아이의 프로필을 만들고,
그다음부터는 매일 `/today` 하나면 그날의 글쓰기와 피드백이 돌아간다. 안에는 글쓰기 템플릿
10종을 넣고, 각 템플릿마다 난이도 3단계를 뒀다. 같은 '설명하는 글'이라도 6학년과 8학년의
눈높이가 다르니, 아이에 맞는 단계에서 시작해 조금씩 올라가게 했다.
